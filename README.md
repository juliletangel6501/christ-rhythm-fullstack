# Christ Rhythm — starter website

This is the first frontend starter for Christ Rhythm.

## Open on Windows
1. Download and extract `christ-rhythm-starter.zip`.
2. Open the extracted `christ-rhythm-starter` folder in Visual Studio Code.
3. Open `index.html` in a browser, or install the VS Code extension **Live Server** and choose **Open with Live Server**.

## Included
- Responsive homepage
- Navigation for Songs, Bible, Daily Verse, Daily Manna, Confessions, Prayer and Resources
- Language selector for Tamil, Malayalam, Telugu, Kannada, Hindi and English
- Search interface placeholder

## Important next steps
This starter is frontend only. The next development stage is to add the Express backend, PostgreSQL database, admin login, media upload, and real translation/content management. The sample text and verse are demonstration content; review Bible translation permissions before publishing.
